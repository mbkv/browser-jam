# Browser Jam 2024

My entry to the [2024 Browser Jam](https://github.com/BrowserJam/browserjam). The goal of the browserjam was to build a program that renders [the first HTML page](https://info.cern.ch/hypertext/WWW/TheProject.html) and contains a lot of interesting edge cases. [My contribution](https://github.com/BrowserJam/jam001/tree/master/mbkv) is a canvas based HTML parser and renderer written entirely from scratch with no external dependencies. There was 1 dependency in that I needed to get around CORS errors with cors-anywhere
